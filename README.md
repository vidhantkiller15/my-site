# RACER-X – Blacklist #1

**Unofficial fan page** for Racer-X from *Need for Speed: Most Wanted* (2005).  
A dark, street-racer styled single-page site with tabs, a Rockport PD terminal aesthetic, and live GitHub project loading.

> tagged by Racer-X.  
> Need for Speed and Most Wanted belong to Electronic Arts.

---

## Features

- **Tabbed interface** with keyboard support (arrow keys, Home/End) and URL hash navigation
- **Who am I** — Lore, wanted status, and a typewriter-style Rockport PD terminal file
- **My rides** — Custom BMW M3 GTR “Razor Build” showcase with click-to-zoom lightbox
- **Blacklist** — Full ranked ladder of Rockport’s 15 most-wanted street racers
- **My projects** — Live-loaded public repositories from GitHub (`vidhantkiller15`)
- Responsive design with noise texture, gold accents, and Permanent Marker / Rock Salt typography
- Accessibility-friendly (ARIA tabs, focus styles, reduced-motion support)
